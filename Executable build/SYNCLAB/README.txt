SYNCLAB - Windows Portable App

Run StudentWorkshopApp.exe to start the application.

Keep the executable, all Qt runtime files and folders, and the data folder together.
The included data\student_data.db starts empty; SYNCLAB creates its tables on first
launch and stores future records in that file. Back it up to preserve saved records.

This build is for 64-bit Windows and includes the Qt 6.11.2 and MinGW 13.1 runtime.
